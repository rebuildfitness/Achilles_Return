# Simplified baseline — user-requested UX extension

The default baseline is now four steps: safety, everyday movement, optional
tests, and save. The detailed assessment remains available. Existing detailed
drafts resume without changing their step or deleting answers.

Safety questions retain the existing validation. Everyday movement asks only
the running-relevant self-reports and two optional confidence scores. Physical
tests are collapsed, optional panels: bilateral raises, heel-rise repetitions
and balance time. Height/work measurements are under More measurements.
Additional mobility and loaded calf tests are optional; the four general
strength exercises have separate optional panels and separate data fields.

Blank measurements remain absent, never a fabricated zero or pass. Each test
has a clear Not tested state and a control to clear only that test. Existing
test restrictions and instructions remain visible when a panel opens. Saving
a baseline does not grant running or sport clearance; those criteria are
unchanged. Numerical entries still receive range validation even in optional
panels. Profile details are reused, but new symptom and test results are not.

Monthly starting/finishing snapshots, history and Progress charts are retained.
Date and personal setup are collapsed; the monthly assessment-point choice
remains visible. All draft and completed data remains local in IndexedDB.
