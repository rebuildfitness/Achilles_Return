# Visual Handoff Checklist

Before Codex implements feature screens:

- [ ] Read `AGENTS.md`
- [ ] Open `assets/design/achilles-return-hero-reference.png` side-by-side
- [ ] Read `docs/DESIGN_SYSTEM.md`
- [ ] Read `docs/VISUAL_SCREEN_SPEC.md`
- [ ] Load tokens from `spec/design-tokens-v1.json`
- [ ] Create reusable app shell/header/bottom-nav/card/status/button components
- [ ] Build Today screen first
- [ ] Verify Today visually matches the central phone language in the hero
- [ ] Preserve criteria-based progression labels instead of copying fake week labels
- [ ] Verify Strong-style full workout list is retained
- [ ] Verify Plan includes weekly plan + calendar/history
- [ ] Verify Short Demo is visible on active exercise cards
- [ ] Verify green/amber/red semantics are correct
- [ ] Verify no unowned equipment appears
- [ ] Run clinical/product tests before moving to next screen group

## First visual approval gate
Do not mass-produce every screen until the Today screen and app shell establish the approved visual language.
