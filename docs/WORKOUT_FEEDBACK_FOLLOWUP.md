# Workout usability follow-up - 1.6.3

- Every exercise swap panel includes a searchable exercise-library browser. Available reviewed replacements can be selected and applied for this session or future sessions. Unavailable entries can be displayed with an explicit reason. Existing clinical swap families, reference restrictions, equipment requirements and readiness rules remain unchanged; the library is not blanket clearance for arbitrary substitutions.
- First-set feedback now automatically fills blank RPE, quality and symptom fields on remaining unfinished sets of the same exercise. Individual overrides and completed sets are preserved. Confirm carried feedback once after the exercise, rather than re-entering each set. No copied feedback is treated as confirmed progression evidence without confirmation.
- Today now has a Rehab & movement support card. Prescribed rehab remains in the full workout; the separate support button opens existing mobility, core and balance routines and activity logging. It does not add another loading session or unlock new routines.

Existing completed history is unchanged. App 1.6.3 uses the existing database and clinical rules versions.
