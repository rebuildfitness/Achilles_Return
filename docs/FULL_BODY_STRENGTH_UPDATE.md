# Full-body strength extension — user-approved scope

The user requested more full-body strength in both the library and the plan,
including 5×5 and hypertrophy, without removing rehabilitation work. This extends
the Master Plan's existing 2–4 upper-body exercises per strength day. Achilles
entry criteria, exposure ladders, red flags and next-morning tolerance remain unchanged.

## Program

The default is Rehab + 5×5 & hypertrophy. More → Profile & schedule also offers
Rehab + hypertrophy and the original rehab template. Existing profiles without
a preference use the new default; reassessment preserves saved preferences.

All original A/B/C exercises and prescriptions remain intact. Added exercises:

| Day | Added work |
| --- | --- |
| A | Incline dumbbell press 5×5; bench-supported dumbbell row 2×8–12/side; lateral raise 2×12–15 |
| B | Bench-supported dumbbell row 5×5/side; seated triceps extension 2×10–15 |
| C | Seated Arnold press 3×8–12; supported row 3×8–12/side; dumbbell curl 2×10–15 |

The hypertrophy preference uses 3×8–12 in the two 5×5 slots. No lower-body or
calf exercise is converted to heavy 5×5. The added work shares existing strength
days, follows rehab, and uses RPE 6–8 (roughly 2–4 reps in reserve). Warm up with
lighter loads; compound rest is 3 minutes for 5×5 and 2 minutes for hypertrophy.
Load is selected by the athlete's demonstrated tolerance, never inferred from
age, calendar phase or a guessed 1RM. Small increases use the existing completed
sets / quality / symptoms / next-morning progression decision.

Yellow readiness converts added work to easier 8–12 reps and at most 3 sets;
Yellow 3 retains only minimal Achilles-load exercises, at most 2 sets, RPE 5–6.
Re-entry reductions and red-flag stops still apply. Reducing added accessory
work when fatigue interferes with rehab is encouraged. This is not a promise
that every prescribed dose suits every athlete.

## Equipment and demos

BOSU ball, dyno pad and plyo ball are registered as user-owned equipment options.
Their presence does not clear unstable balance or impact training. User photos
identify the dyno pad as a Trideer inflatable balance cushion, the plyo ball as
a Trideer stability/yoga ball, the half ball as VEVOR, and an AXV vibration plate.
These are inventory options, not automatic exercise prescriptions. Internal IDs
are retained for compatibility; visible labels use the clarified names. Existing saved equipment selections remain
intact and can be edited in More. No standalone rack is assumed for free-bar
bench/squats. Olympic barbell curls are in the library with a 45 lb minimum-bar
warning; the scheduled curl remains the more adjustable dumbbell version.

## Evidence limits

[ACSM general resistance-training guidance](https://acsm.org/effective-resistance-training-program-infographic/)
supports strength and muscle development. The exact 5×5 prescription is a
user-requested programming choice, not a proven Achilles-rehabilitation dose
or clearance test. Added exercise metadata identifies this distinction.

Plan rule IDs: template.strength-A/B/C.full-body.v1; existing clinical rules
and strength progression criteria are retained. Data stays local in IndexedDB.
