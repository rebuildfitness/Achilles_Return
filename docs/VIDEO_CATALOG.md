## Before activation
The following require a final direct short-demo URL before being made active:
- knee-to-wall mobility
- band/cable hamstring curl
- snap-down
- countermovement jump
- lateral line hop
- 45° cut
- 90° cut
- soccer skill cards

Codex should not substitute a random long video. It should leave the exercise locked and surface a development warning if the demo requirement is unmet.
